# Idle Drive Detection and Workload Migration

## Description
The Idle Drive Detection and Workload Migration system is designed to monitor drive utilization, identify idle or underutilized drives, and help users manage storage resources efficiently. The system displays drive usage details and allows users to manually migrate workloads from one drive to another based on utilization levels.

## Features
- **User Login:** Provides a login page for accessing the system.
- **Dashboard:** Displays drive utilization information.
- **Drive Details:** Allows users to view individual drive usage and status.
- **Idle Drive Detection:** Identifies drives with low utilization.
- **Workload Migration:** Allows users to manually select and migrate workloads between drives.
- **Drive Monitoring:** Helps users understand storage utilization across multiple drives.
- **User-Friendly Interface:** Provides simple navigation between system pages.

## Project Objective
- To identify idle and underutilized drives.
- To improve storage resource utilization.
- To help users manage workloads efficiently.
- To provide manual control over workload migration.
- To simplify drive monitoring and management.

## System Workflow
1. The user logs in to the system.
2. The dashboard displays the available drives and their utilization.
3. The user views the details of each drive.
4. The system helps identify idle or underutilized drives.
5. The user selects the source and destination drives.
6. The user initiates the workload migration manually.
7. The updated drive information is displayed.
